# Azure Blue-Green Deployment Demo

This project demonstrates Blue-Green deployment using Azure App Service Deployment Slots.

## Stack
- Flask
- Azure App Service
- Deployment Slots

## Deployment Flow
1. Deploy Blue to Production
2. Deploy Green to Staging
3. Validate Staging
4. Swap Slots
